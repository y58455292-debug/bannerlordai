Implementation scope
--------------------
- Added an Evidence-profile-only observer in the existing ClanAIPostVanilla.Postfix hourly AI decision seam.
- Observer rechecks strict ordinary NPC lord eligibility. Main player, army, caravan, disabled/stopped AI, prisoner, child/template, attached, battle/siege, disbanding/waiting, inactive, invalid/leaderless and non-lord states are skipped. Parties currently at sea are not skipped; every indexed route point is separately checked in native land and sea navigation modes.
- Reads MobileParty.Path directly at indices PathBegin through min(PathBegin+8, Path.Size); does not copy the path or invoke native path computation. It samples at most 8 points per admitted party.
- Bounded process-local quota: at most 4 distinct party StringIds per CampaignTime hour, duplicate suppression, session reset. Aggregate quota and duplicate skip counts are included in subsequent admitted Evidence records.
- Each point is classified using native land-valid/sea-invalid navigation; both/neither-valid points fail open as unknown. Land classification reuses the 5 map-unit, maximum-8 nearby-settlement classifier plus an overflow probe. Selected settlement identity is resolved directly and its current owner Kingdom is read live; no global kingdom/settlement/party scan.
- Explicit closure is checked directionally as sampled zone kingdom > visitor kingdom. War skips only when visitor Kingdom.IsAtWarWith(the sampled zone Kingdom). No call to BlocksVisit; border filter counters are unchanged.
- Evidence records report status closed_zone_sample_observed / no_closed_zone_in_samples / unavailable / partial, path size/begin, sampled and truncated counts, sea/unknown counts, sampled kingdom/settlement IDs, closure direction, zone-war skips, errors, and cumulative quota/duplicate skips.
- No candidate, score, target, route, movement, or save mutation. Radius and result limits bound requested work/calls but are not a hard native execution-time guarantee.

-------------------

EventPositionAdder reads Path[PathBegin] and increments PathBegin when a point is reached, then movement uses the current PathBegin point. Observer labels its result as stored-path samples; the samples do not guarantee future traversal or represent the full route.
Retained route research also establishes: native full-path query has no work-budget parameter; distance query has no waypoints; private ComputePath mutates live movement; face-group exclusions identify invalid terrain classes, not kingdom borders. No such path computation or face ownership inference is used here.
