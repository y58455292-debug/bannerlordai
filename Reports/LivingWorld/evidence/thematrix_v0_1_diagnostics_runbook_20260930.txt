CODE REVIEW FINDINGS (GitHub main source)
- RuntimeProfile.ConfigPath resolves to the installed module's Data/RuntimeProfile.cfg via ModuleRuntimePaths.Data.
- RuntimeProfile defaults to Release when the file is missing, unreadable, or invalid. Profile=Evidence opts into Evidence; its static _loaded cache means the profile is read once per game process and changes require a full process restart.
- ClanAIDiagnostics is internal and Snapshot(string,bool) is private. No user-callable UI/console command exists.
- On campaign session launch, diagnostics automatically write a session_begin snapshot if Evidence-enabled session logging created a path. Subsequent snapshots occur after the frame gate and 30-second throttle, after save-boundary follow-up, and at session end. On module unload, shutdown-health output may be written.
- Snapshot path is a .diagnostics.txt sibling of the module session log under Modules/ClanAI/Logs/Sessions. It contains KINGDOM_BORDER_DESTINATION_FILTER candidateChecks/candidatesFiltered.
- Evidence profile also enables existing Civic Project and Local Manpower telemetry, adds Generational Continuity Preflight, Phase 4A Recovery Observer and Dynasty Structural Runtime Observer hooks, and writes further log/telemetry files. It adds IO/runtime work and is not equivalent to Release-profile testing.
- RuntimeProfile.cfg is intentionally absent from the default package, preserving Release-by-default.
