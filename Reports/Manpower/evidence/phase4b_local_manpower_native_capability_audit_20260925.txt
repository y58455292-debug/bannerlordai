NATIVE PIPELINE FINDINGS
- RecruitmentCampaignBehavior registers DailyTickSettlementEvent.
- Daily settlement update evaluates living recruit-capable notables with six VolunteerTypes slots.
- Each slot calls Campaign.Current.Models.VolunteerModel.GetDailyVolunteerProductionProbability(hero,index,settlement).
- Successful empty-slot production uses VolunteerModel.GetBasicVolunteer.
- Successful occupied-slot production may upgrade via native UpgradeTargets, notable power and MaxVolunteerTier.
- DefaultVolunteerModel MaxVolunteerTier=4.
- DefaultVolunteerModel GetBasicVolunteer returns culture EliteBasicTroop for rural notable in a castle-bound village; otherwise culture BasicTroop.
- Default daily probability has slot-index decay plus kingdom fief-count compensation, Cantons, mounted-slot perk, and game recruitment-rate option.
- Local security and village hearth do not directly enter DefaultVolunteerModel volunteer production.
- Local town prosperity only enters indirectly through the kingdom-wide fief-count compensation, not as a direct settlement multiplier.
- RecruitmentVM reads notable VolunteerTypes and clears the exact purchased slot for player recruitment.
- Ordinary AI settlement recruitment reads the same VolunteerTypes and clears the exact recruited slot.
- Garrison auto recruitment can consume the same notable slots from the fortification/bound villages.
- Garrison base change separately can add BasicTroop without visible volunteer slots.
- Minor-faction AI parties have a separate map-recruit path outside settlements that does not consume notable slots.

populationFactor:
  native High=1.00
  native Mid=0.95
  native Low=0.80

securityFactor:
  0.80 + 0.20 * clamp(security,0,50)/50
  clamp to [0.80,1.00]
  town uses own Town.Security
  village uses bound fortification Town.Security when available
  missing security -> 1.00

acuteFactor:
  active under raid or under siege -> 0.50
  otherwise -> 1.00

localMultiplier =
  clamp(populationFactor * securityFactor * acuteFactor, 0.35, 1.00)

for empty slot:
  p_final = clamp(p_native * localMultiplier, 0, 1)

for occupied slot:
  p_final = p_native exactly
