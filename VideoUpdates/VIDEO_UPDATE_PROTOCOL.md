# BannerlordAI Video Update Protocol

Capture video only for important evidence:
- major breakthrough / accepted milestone
- unexpected blocker or failure
- rollback / recovery event
- visible behavior change worth comparing

Rules:
- Record the Bannerlord client window only.
- Do not record unrelated desktop windows.
- Default 10 FPS, max 1280 px width.
- Keep clips short around the decisive moment.
- Save under D:\BannerlordAIResearch\VideoUpdates.
- Name clips with checkpoint/version + event + timestamp.
- Written validation/log evidence remains authoritative.
- Video is supplemental visual evidence, never the sole acceptance proof.

Chat delivery:
- Remote Desktop Commander can create the local MP4 but cannot directly attach a PC file to this chat.
- Use a connected Drive/Dropbox-style file connector or manual chat attachment to surface the MP4 here.
