BANNERLORDAI — ACTOR STRATEGIC BLACKBOARD v0.20N REVIEW
Date: 2026-09-18 Pacific.

Goal:
Measure natural strategic intent stability and switch conditions before designing any hysteresis/commitment intervention.

Prior-art basis:
- Epic blackboard/behavior-tree architecture: per-agent state belongs in a compact blackboard; shared decision logic remains stateless.
- BDI intention-reconsideration research: commitment quality depends on when intentions are reconsidered.
- Utility-AI prior art: bounded hysteresis can prevent action flip-flopping, while selection remains separate from execution.
- BannerlordAI doctrine: native execution remains authoritative.

Architecture:
- session-only dictionary keyed by actor/party ID
- one bounded record per observed lord
- updated only at StrategicDecisionComposer completion boundary
- no global scans
- no save serialization
- no score/behavior/movement writes
- no new factor formulas

Recorded state:
- coarse strategic state
- objective signature: behavior + stable target ID, or quantized map point for point objectives
- objective start campaign hour
- reconsideration count
- objective and coarse-state switch counts
- final winner and runner-up score gap
- previous objective eligibility on switch
- previous objective score if still legal
- required factor to retain old objective
- switch reason

Coarse states:
Recover, Travel, Defend, Patrol, Secure, Raid, Campaign, Pursue, Support, Retreat, Other.
Classification uses final behavior plus existing composer contribution reasons; it does not infer hidden motives.

Main measurement:
When a natural objective switch occurs:
A) previous objective no longer exists/eligible
or
B) previous objective is still legal but loses on utility score.

For B:
- measure switch gap
- measure required retention factor
- count <=5%, <=10%, <=20% switches.

This provides empirical hysteresis calibration instead of choosing an arbitrary commitment bonus.
