BannerlordAI v0.2.10.43 - Strict non-executing deliberation advisory response admission contract

Question
Can BannerlordAI define and validate the smallest safe structured output contract for a future reasoner before any real model is invoked, while keeping advisory output disconnected from gameplay?

Prior art
- SeverActions: high-level intent/advisory output must remain separate from registered/legal deterministic execution.
- SkyrimNet layered cognition: reasoning output is a separate cognition layer, downstream actions remain separately gated.
- v0.2.10.41 provides a deterministic requestFingerprint.
- v0.2.10.42 provides route eligibility and duplicate suppression before expensive cognition.

Smallest contract
- Runner-only pure parser/validator. No model/network call.
- Schema: BannerlordAI.PatrolDefenseDeliberationAdvisory.v1
- Required fields only:
  schema
  requestFingerprint
  disposition
- Allowed disposition enum:
  KEEP_BASELINE
  REVIEW_ALTERNATIVE
  ABSTAIN
- Admission requires:
  exact schema,
  exact requestFingerprint match to the originating deliberation request,
  disposition in the bounded enum,
  no missing fields.
- Unknown/extra action-bearing fields are rejected. Explicitly reject keys such as:
  action, target, score, scoreDelta, movement, apply, command.
- Admitted result emits BannerlordAI.PatrolDefenseDeliberationAdvisoryAdmission.v1:
  admitted true/false,
  disposition or null,
  rejectionReasons[],
  requestFingerprint,
  advisoryOnly=true,
  executionAuthorized=false,
  interpretationApplied=false,
  behaviorMutation=false,
  intentMutation=false,
  scoreMutation=false,
  nativeMovementCalls=0.
- No response is generated in live runtime yet. This is a contract/validator milestone only.

Acceptance
A. Runner/helper compiles; ClanAI unchanged.
B. Pure fixtures:
   all three allowed dispositions admitted when fingerprint matches;
   wrong fingerprint rejected;
   missing fingerprint/disposition/schema rejected;
   unknown disposition rejected;
   action/target/score/command extra fields rejected;
   malformed JSON rejected;
   admitted result never authorizes execution;
   request fingerprint copied exactly.
C. Static proof: no HTTP/OpenAI/model/planner invocation, no Apply, no score write, no memory write.
D. No Bannerlord live run required; this is a deterministic contract gate.
E. Do not invoke a model until this admission contract is accepted.

Scope
This gate validates transport/schema only. It does not decide which disposition is correct, generate a response, select a model, or affect gameplay.
