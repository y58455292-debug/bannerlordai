# BannerlordAI Daily Office Plan — 2026-09-21

Office mode: **OPEN**
Primary bottleneck: **ROADMAP_NEXT_GATE / front**

## Sequence
- Front resolves/defines next smallest gate.
- Analyzer facilitates evidence/prior-art review if needed.
- Front registers deterministic work only after acceptance criteria are explicit.

## Departments
### Front Office / Coordinator
- State: CLOCKED_IN_CONTROLLER
- Objective: Own the full PLAN -> EXECUTE -> VERIFY roadmap loop, maintain durable state, and publish only material updates.
- Completion: Daily plan current, bottleneck explicit, next handoff assigned.
- Escalation: Integrity incident, conflicting priorities, or work cannot be routed without new user decision.
### Coder / Operator
- State: INTERNAL_STANDBY
- Objective: Stand by for the next roadmap packet.
- Completion: One terminal work packet; coder_status + Analyzer intake written.
- Escalation: New architecture required, integrity drift, repeated failure, or task exceeds shift/WIP boundary.
### Analyzer / Archivist
- State: INTERNAL_STANDBY
- Objective: Internal VERIFY capability stands by; no separate Analyzer chat is required for routine review.
- Completion: Evidence classified; durable lessons/index updated; next gate handed to Front/Coder.
- Escalation: Contradictory evidence, unknown causality, or major architecture/policy change requiring collaboration.
### Supervisor / Platform
- State: CLOCKED_IN
- Objective: Enforce manual office power, WIP, ownership, integrity and registered-action dispatch. Never invent work.
- Completion: No unauthorized/duplicate work; registered queue accurately reflected.
- Escalation: Clock/lease/hash conflict, dispatch failure, or incident trigger.
