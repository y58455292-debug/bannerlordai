DEEPSEEK FILE-READ + COMPRESSION METHOD
Saved: 2026-09-18

Purpose:
Use DeepSeek as a high-volume reader/compactor for BannerlordAI evidence without allowing compression to replace source truth.

Pipeline:
1. RAW EVIDENCE IS IMMUTABLE
   - telemetry
   - session logs
   - behavior-delta CSVs
   - screenshots/keyframes
   - save checkpoints
   - source/build hashes

2. DETERMINISTIC PREPROCESS
   - normalize schemas
   - deduplicate
   - classify known event types
   - preserve timestamps
   - preserve evidence/file IDs
   - split into bounded structured batches

3. DEEPSEEK BULK READ
   - read large batches
   - summarize patterns/anomalies
   - compress repeated evidence
   - retain evidence references for every important claim
   - mark unknown/uncertain rather than infer

4. DETERMINISTIC VERIFICATION
   - compare compressed claims to raw files
   - reject unsupported claims
   - distinguish NATURAL / INDUCED / RESPONSE
   - distinguish candidate score / commitment / reassertion / consequence

5. SENIOR REVIEW
   - GPT-5.6 Sol + human review
   - promote only verified conclusions to project memory / reports

HIERARCHICAL COMPRESSION:
raw events
-> short-window/minute summaries
-> campaign-day summaries
-> session summary
-> build summary
-> cross-build conclusions

Rules:
- Never delete or overwrite raw evidence because a summary exists.
- Compression is an index and reasoning layer, not the source of truth.
- Important conclusions must retain exact evidence references.
- Unknown stays UNKNOWN.
- Prefer structured summaries over prose when feeding later stages.
- Save checkpoints of evolving campaign state so later analysis can study how memory/behavior develops over time.
