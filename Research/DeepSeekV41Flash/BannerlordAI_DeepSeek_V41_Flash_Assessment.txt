External high-volume analyst / compactor / anomaly scout.

WHY IT FITS
Long test sessions can create millions of repetitive telemetry tokens.
V4.1 Flash has:
- huge context;
- cheap input;
- automatic caching;
- strong code/agent benchmark results;
- native image understanding;
- controllable thinking.
This makes it useful for reading far more evidence than we should manually keep in one chat context.

CRITICAL LESSON FROM 2026-09-18 TEST
Do NOT feed raw noisy telemetry directly and trust the summary.
Our own deterministic analysis found:
- some VISUAL_WAR_WINNER_CHANGE events were NEW commitments;
- many were ALREADY_ACTIVE reassertions;
- some remained UNPROVEN.
A language model could easily count all of them as separate meaningful changes.
Therefore preprocessing remains mandatory.

RECOMMENDED PIPELINE
1. Raw Evidence Store (immutable)
   logs, CSV, screenshots/keyframes, build hashes, interventions.

2. Deterministic Normalizer
   labels:
   - NATURAL vs INDUCED stimulus
   - NEW_COMMITTED_CHANGE
   - MAINTAINED / REASSERTED INTENT
   - TRUE INTENT CHANGE
   - UNPROVEN
   - memory event linkage
   - build/session/timestamp IDs

3. DeepSeek Bulk Analyst
   consumes normalized event batches and selected images.
   Strict JSON output with evidence IDs only.

4. Deterministic Verifier
   scripts test DeepSeek's candidate chains against timestamps and Behavior Delta.

5. Senior Review
   GPT-5.6 Sol / human evaluates important engineering conclusions and decides what patch to test.

6. Longitudinal Store
   session summaries, build comparisons, regressions, unresolved findings.

SATURATION-RESISTANT CONTEXT DESIGN
Do not use 1M tokens as an excuse to append forever.
Use hierarchy:
- raw evidence permanently on disk;
- minute/hour rollups;
- campaign-day episode summaries;
- session summaries;
- build summaries;
- cross-build conclusions.

Keep stable request prefix:
- project doctrine;
- data schema;
- current build manifest;
- proof rubric;
- output JSON schema;
- previous frozen summary.
Append only new normalized evidence.
This maximizes automatic DeepSeek prefix-cache reuse.

MULTIMODAL USE
For video:
- keep raw video locally;
- extract timestamped keyframes / short representative frame sequences;
- pair frames with telemetry windows;
- ask DeepSeek to identify visible map state and possible patterns;
- require frame IDs + event IDs in every claim.
Do not assume raw video upload support.

REASONING ROUTING
- Non-thinking / low: tagging, classification, dedupe review, routine compaction.
- High: anomaly grouping, cross-session comparison, code/log analysis.
- Max: rare candidate causal chains or difficult architectural analysis.
Never use max reasoning by default for bulk ingestion.

LOCAL HOSTING
Not realistic on a normal gaming PC.

Use hosted API for this role unless future quantizations become dramatically smaller.

PRIVACY / SAFETY PRACTICE

Keep canonical raw evidence locally and transmit only project data required for analysis.
Strip API keys, personal paths/names, unrelated files, and secrets before sending.
